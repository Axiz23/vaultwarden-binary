**This is un-official prebuilt [Vaultwarden](https://github.com/dani-garcia/vaultwarden) binary**.

You can download the Vaultwarden binary in [Releases](https://github.com/Axiz23/vaultwarden-binary/releases) pages!

## How to install & Run
1. Download binary and Choose the version you want
2. Extract the ZIP file.
3. Run ```./vaultwarden-amd64-musl``` or ```./vaultwarden-arm64-musl```

## Information
- Binary only, Web Vault is not included. Download [WebVault](https://github.com/dani-garcia/bw_web_builds/releases/tag/v2026.7.0)
- Release may be delayed after upstream updates
